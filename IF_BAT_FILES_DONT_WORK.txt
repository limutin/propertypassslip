The .bat files might not work because of Windows security or
PowerShell restrictions. No problem! Here's the better way:


┏━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┓
┃  USE COMMAND PROMPT INSTEAD (More Reliable!)                ┃
┗━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┛


═══════════════════════════════════════════════════════════════
STEP A: OPEN COMMAND PROMPT IN YOUR PROJECT FOLDER
═══════════════════════════════════════════════════════════════

Method 1 (Easiest):
───────────────────
  1. Press Windows key + E (opens File Explorer)
  
  2. Navigate to:
     c:\Users\ACER\Desktop\PropertyPassslip\propertypassslip
  
  3. Click in the ADDRESS BAR at the top
     (where it shows the folder path)
  
  4. The path will be highlighted in blue
  
  5. Type: cmd
  
  6. Press Enter
  
  7. A black window (Command Prompt) will open
     in your project folder!


Method 2 (Alternative):
───────────────────────
  1. Press Windows key
  
  2. Type: cmd
  
  3. Press Enter
  
  4. A black window opens
  
  5. Type this command:
     cd "c:\Users\ACER\Desktop\PropertyPassslip\propertypassslip"
  
  6. Press Enter
  
  7. You're now in your project folder!


═══════════════════════════════════════════════════════════════
STEP B: RUN THESE COMMANDS ONE BY ONE
═══════════════════════════════════════════════════════════════

Copy each command, paste into Command Prompt, press Enter.
Wait for each to finish before running the next one.


┌─────────────────────────────────────────────────────────────┐
│  COMMAND 1: Login                                           │
└─────────────────────────────────────────────────────────────┘

Type this:

  npx firebase-tools login

Then press Enter.

What happens:
  • You'll see "Waiting for authentication..."
  • Your web browser opens
  • Sign in with your Google account
  • Browser shows "Success!"
  • Close the browser
  • Go back to Command Prompt
  • You'll see "✔ Success! Logged in as..."

✅ Done? Continue to Command 2.


┌─────────────────────────────────────────────────────────────┐
│  COMMAND 2: Connect to Your Project                         │
└─────────────────────────────────────────────────────────────┘

Type this:

  npx firebase-tools init

Then press Enter.

Now answer these questions:

┌─────────────────────────────────────────────────────────────┐
Question: Which Firebase features?

You'll see a list like:
  ( ) Firestore
  ( ) Functions
  ( ) Hosting
  ( ) Storage

ACTION:
  • Press DOWN ARROW until you reach "Hosting"
  • Press SPACEBAR (you'll see it marked with X or *)
  • Press ENTER
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
Question: Please select an option

You'll see:
  Use an existing project
  Create a new project

ACTION:
  • Make sure "Use an existing project" is selected
  • Press ENTER
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
Question: Select a default Firebase project

You'll see a list of your Firebase projects.

ACTION:
  • Press DOWN ARROW to find YOUR project
  • Press ENTER
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
Question: What do you want to use as your public directory?

You'll see: (public)

ACTION:
  • Type: dist
  • Press ENTER
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
Question: Configure as a single-page app?

You'll see: (y/N)

ACTION:
  • Type: Y
  • Press ENTER
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
Question: Set up automatic builds and deploys with GitHub?

You'll see: (y/N)

ACTION:
  • Type: N
  • Press ENTER
└─────────────────────────────────────────────────────────────┘

You'll see:
  ✔ Firebase initialization complete!

✅ Done? Continue to Command 3.


┌─────────────────────────────────────────────────────────────┐
│  COMMAND 3: Install Packages                                │
└─────────────────────────────────────────────────────────────┘

Type this:

  npm install

Then press Enter.

What happens:
  • You'll see lots of text scrolling
  • This takes 1-2 minutes
  • Wait until you see the prompt (C:\...\propertypassslip>)

✅ Done? Continue to Command 4.


┌─────────────────────────────────────────────────────────────┐
│  COMMAND 4: Build Your Project                              │
└─────────────────────────────────────────────────────────────┘

Type this:

  npm run build

Then press Enter.

What happens:
  • You'll see "vite v..." and building progress
  • Takes about 30 seconds
  • You'll see "✓ built in X.XXs"
  • A "dist" folder is created

✅ Done? Continue to Command 5.


┌─────────────────────────────────────────────────────────────┐
│  COMMAND 5: Deploy to Firebase! 🚀                          │
└─────────────────────────────────────────────────────────────┘

Type this:

  npx firebase-tools deploy --only hosting

Then press Enter.

What happens:
  • You'll see "Deploying to 'your-project'..."
  • Takes 1-2 minutes
  • You'll see:

    ✔  Deploy complete!
    
    Project Console: https://console.firebase.google.com/...
    Hosting URL: https://your-project-id.web.app

THAT'S YOUR LIVE WEBSITE URL! 🎉

✅ COPY THAT URL!


═══════════════════════════════════════════════════════════════
STEP C: OPEN YOUR LIVE WEBSITE
═══════════════════════════════════════════════════════════════

  1. Copy the Hosting URL from Command 5
  
  2. Open your web browser
  
  3. Paste the URL in the address bar
  
  4. Press Enter
  
  5. YOUR WEBSITE IS LIVE! 🎊

❓ STILL HAVING ISSUES?
═══════════════════════════════════════════════════════════════

Issue: "npx is not recognized"
→ Install Node.js from https://nodejs.org/
→ Download the LTS version
→ Install it
→ Restart Command Prompt
→ Try again

Issue: "Error: Not authorized"
→ Run: npx firebase-tools login

Issue: "Build failed"
→ Check that you updated src/firebase/config.js
→ It should have real Firebase values, not "YOUR_API_KEY"

Issue: Command Prompt closes immediately
→ That's normal for .bat files
→ Use this Command Prompt method instead

Issue: "Cannot find module"
→ Run: npm install
→ Then try again

Issue: Website shows blank page
→ Did you update src/firebase/config.js?
→ Check browser console (F12) for errors
