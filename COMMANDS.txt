────────────────────────────────────────────────────────────────
COMMAND 1: Login to Firebase
────────────────────────────────────────────────────────────────
npx firebase-tools login

[Browser will open → Sign in → Close browser → Come back]
────────────────────────────────────────────────────────────────


────────────────────────────────────────────────────────────────
COMMAND 2: Initialize Firebase
────────────────────────────────────────────────────────────────
npx firebase-tools init

[Answer questions:
 - Features: SPACEBAR on "Hosting", then ENTER
 - Project: "Use existing project", ENTER
 - Which project: Choose yours, ENTER
 - Public directory: Type "dist", ENTER
 - Single-page: Type "Y", ENTER
 - GitHub: Type "N", ENTER]
────────────────────────────────────────────────────────────────


────────────────────────────────────────────────────────────────
COMMAND 3: Install Dependencies
────────────────────────────────────────────────────────────────
npm install

[Wait 1-2 minutes...]
────────────────────────────────────────────────────────────────


────────────────────────────────────────────────────────────────
COMMAND 4: Build Project
────────────────────────────────────────────────────────────────
npm run build

[Wait 30 seconds...]
────────────────────────────────────────────────────────────────


────────────────────────────────────────────────────────────────
COMMAND 5: Deploy to Firebase!
────────────────────────────────────────────────────────────────
npx firebase-tools deploy --only hosting

[Wait 1-2 minutes...]
[Copy the Hosting URL that appears!]
