┌─────────────────────────────────────────────────────────────────────┐
│  STEP 1: Get Firebase Project Settings                             │
│  ═══════════════════════════════════════                            │
│                                                                       │
│  1. Open browser → https://console.firebase.google.com/             │
│  2. Click your project                                              │
│  3. Click ⚙️ Settings → Project Settings                            │
│  4. Scroll down to "Your apps"                                      │
│  5. Click </> (Web app) OR add new web app                          │
│  6. COPY the config (looks like JavaScript code)                    │
│                                                                       │
│  ✓ You should have copied something that looks like:                │
│    const firebaseConfig = {                                         │
│      apiKey: "AIza...",                                             │
│      authDomain: "...",                                             │
│      ...                                                            │
│    };                                                               │
└─────────────────────────────────────────────────────────────────────┘
                               ↓
┌─────────────────────────────────────────────────────────────────────┐
│  STEP 2: Update Your Code                                           │
│  ═════════════════════════                                           │
│                                                                       │
│  1. Open file: src/firebase/config.js                               │
│  2. Find the part with "YOUR_API_KEY", etc.                         │
│  3. REPLACE with what you copied in Step 1                          │
│  4. SAVE the file (Ctrl + S)                                        │
│                                                                       │
│  ✓ Check: config.js should now have real values, not "YOUR_..."    │
└─────────────────────────────────────────────────────────────────────┘
                               ↓
┌─────────────────────────────────────────────────────────────────────┐
│  STEP 3: Login to Firebase                                          │
│  ══════════════════════════                                          │
│                                                                       │
│  📁 Find file: firebase-login.bat                                   │
│  🖱️  Double-click it                                                │
│  🌐 Browser opens → Sign in with Google                             │
│  ✅ See "Success" message                                           │
│  🚪 Close browser                                                   │
└─────────────────────────────────────────────────────────────────────┘
                               ↓
┌─────────────────────────────────────────────────────────────────────┐
│  STEP 4: Connect to Your Firebase Project                           │
│  ══════════════════════════════════════════                          │
│                                                                       │
│  📁 Find file: firebase-init.bat                                    │
│  🖱️  Double-click it                                                │
│  ❓ Answer questions:                                               │
│     • Features? → Press SPACEBAR on "Hosting", then ENTER           │
│     • Project? → Choose "Use existing project", ENTER               │
│     • Which project? → Select YOUR project name, ENTER              │
│     • Public directory? → Type: dist, ENTER                         │
│     • Single-page app? → Type: Y, ENTER                             │
│     • GitHub? → Type: N, ENTER                                      │
│  ✅ See "Firebase initialization complete"                          │
└─────────────────────────────────────────────────────────────────────┘
                               ↓
┌─────────────────────────────────────────────────────────────────────┐
│  STEP 5: Deploy Your Website!                                       │
│  ═════════════════════════════                                       │
│                                                                       │
│  📁 Find file: deploy.bat                                           │
│  🖱️  Double-click it                                                │
│  ⏳ Wait... (takes 3-5 minutes)                                     │
│     • Installing dependencies... ████████░░ 80%                     │
│     • Building project...       ██████████ 100%                     │
│     • Deploying to Firebase...  ██████████ 100%                     │
│  ✅ See "Deploy complete!"                                          │
│  🌐 See your URL: https://your-project.web.app                      │
└─────────────────────────────────────────────────────────────────────┘
                               ↓
┌─────────────────────────────────────────────────────────────────────┐
│  STEP 6: Open Your Live Website! 🎉                                 │
│  ═══════════════════════════════════                                 │
│                                                                       │
│  1. Copy the URL from Step 5                                        │
│  2. Open your browser                                               │
│  3. Paste the URL                                                   │
│  4. Press Enter                                                     │
│                                                                       │
│  🎊 YOUR WEBSITE IS LIVE!                                           │
│  🌍 Anyone can access it from anywhere!                             │
└─────────────────────────────────────────────────────────────────────┘
