# 🚀 START HERE - Property Pass Slip Web Tracker

Welcome! This is your complete Property Pass Slip Web Tracker for DILG Misamis Occidental Provincial Office.

## 📋 What is this?

A modern web application that digitizes the property pass slip process, allowing employees to request property borrowing online and administrators to track everything in a centralized dashboard.

## 🎯 What You'll Build

### For Public Users:
- **Landing Page**: Clean homepage with navigation
- **Pass Slip Form**: Submit property borrowing requests
- **PDF Generation**: Automatic PDF matching official DILG template
- **Email Confirmation**: Receive PDF copy via email

### For Administrators:
- **Secure Login**: Protected admin access
- **Dashboard**: Real-time analytics and charts
- **Pass Slip Management**: View, search, filter all submissions
- **Return Tracking**: Mark items as returned with details

## 🛠️ Tech Stack

```
Frontend:       React 18 + Vite
Styling:        Tailwind CSS
Backend:        Firebase (Firestore + Auth + Storage)
Charts:         Chart.js
PDF:            jsPDF
Routing:        React Router DOM
```
